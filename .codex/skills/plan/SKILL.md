# 计划模式技能

先分析需求生成分步执行计划，批准后再执行。

## 使用指南

1. 发送需求后，先分析并输出分步执行计划
2. 每步用编号列表分行列出
3. 计划可编辑（修改/删除/重排序）
4. 批准后按计划逐步执行
5. 执行过程中每步显示结果
